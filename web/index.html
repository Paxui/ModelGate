关于 ModelGate

      
    

    

      

        ModelGate 由 Rust、Axum 与原生 Web GUI 构建，提供本地 OpenAI-Compatible 模型路由服务。
        管理界面通过本机 Management API 保存配置；Gateway 默认只监听 127.0.0.1。
